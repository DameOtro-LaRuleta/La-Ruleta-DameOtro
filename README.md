# 🎲 LA RULETA – DameOtro (Web App)

Aplicación web gamificada, interactiva y responsive diseñada para DameOtro. Permite a los clientes descubrir la colección de los 8 sabores mediante la lectura de un código QR en tienda o empaques.

---

## 🚀 Guía de Publicación Gratuita en GitHub Pages

### Paso 1: Crear el Repositorio en GitHub
1. Inicia sesión en tu cuenta de [GitHub](https://github.com/).
2. Haz clic en el botón **New** (Nuevo repositorio).
3. Nombre del repositorio: `ruleta-dameotro` (o el de tu preferencia).
4. Asegúrate de marcarlo como **Public** (Público).
5. Haz clic en **Create repository**.

### Paso 2: Subir los Archivos
1. En la página del repositorio recién creado, haz clic en **uploading an existing file**.
2. Arrastra los 3 archivos principales:
   - `index.html`
   - `style.css`
   - `script.js`
3. Presiona el botón verde **Commit changes**.

### Paso 3: Activar GitHub Pages
1. Dentro de tu repositorio, ve a la pestaña **Settings** (Configuración) en la parte superior.
2. En el menú lateral izquierdo, haz clic en **Pages**.
3. En la sección **Build and deployment** -> **Branch**:
   - Cambia `None` por **`main`** (o `master`).
   - Deja la carpeta en `/ (root)`.
4. Haz clic en **Save**.

### Paso 4: Obtener tu URL Pública
1. Espera entre 1 y 2 minutos.
2. Recarga la página de **Pages**. Verás un mensaje en verde con tu enlace listo:
   `https://tu-usuario.github.io/ruleta-dameotro/`

## 📲 Integración con Linktree y Código QR

1. **Linktree**: Copia la URL de GitHub Pages y agrégala como un botón destacado llamado: **"🎲 Juega a La Ruleta de Sabores"**.
2. **Código QR**:
   - Ingresa a un generador gratuito como [QR Code Generator](https://www.qr-code-generator.com/).
   - Pega tu URL de GitHub Pages.
   - Descarga el código QR en alta resolución e imprímelo en los empaques y exhibidores de caja de **DameOtro**.
